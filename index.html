《生存日记》隐私政策

更新日期：2026年11月25日  |  生效日期：2026年11月25日

导言

五月四工作室（以下简称“我们”）是《生存日记》（以下简称“本游戏”）的开发者/运营者。本游戏是一款纯单机生存游戏。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全。

本政策旨在向您说明，在您使用本游戏时，我们（及第三方广告服务商）如何收集、使用和保护您的信息，以及您所享有的权利。

请在使用本游戏前，仔细阅读并充分理解本政策。 如您点击“同意”或实际使用本游戏，即表示您已理解并同意本政策的全部内容。

一、我们收集和使用的信息

我们遵循“合法、正当、必要和诚信”原则，仅收集实现游戏功能所必需的信息。

（一）核心玩法与本地数据

《生存日记》（基于 Survival Template Pro 框架开发）的核心玩法（探索、建造、制作、生存状态管理、本地存档等）完全在您的设备本地运行，不需要联网，我们不会收集、上传或保存您的任何游戏存档数据。

游戏过程中产生的所有数据（包括但不限于：生存天数、角色状态、物品栏、建造进度、设置偏好）均仅保存在您的设备本地。您可以通过清除应用数据或卸载游戏来删除这些本地数据。

（二）广告服务（Google Mobile Ads）

本游戏接入了由 Google 提供的广告服务（Google Mobile Ads / AdMob）。为了向您提供广告展示、防止欺诈以及计算广告效果，Google Mobile Ads SDK 可能会自动收集以下信息：

  • 设备标识符（如 Android 广告 ID / OAID、iOS 广告标识符 IDFA）。
  • 设备信息（设备型号、操作系统版本、系统语言）。
  • 网络信息（IP 地址、网络连接类型）。
  • 广告交互数据（广告的展示次数、点击记录）。

注：上述信息由 Google 直接收集，我们不会将其与您的真实身份进行关联。

（三）个性化广告与您的选择

在适用的法律要求下（如欧洲经济区、英国等），我们会在首次启动游戏或广告加载前，通过 Google UMP（用户消息平台） 弹窗向您征求广告数据使用同意。您可以选择“同意”以接收个性化广告，或选择“不同意”以继续接收非个性化广告。

您有权拒绝个性化广告。 如果您拒绝，您依然可以正常游玩本游戏，只是看到的广告将与您的兴趣无关。您可以随时在手机系统设置中（如：Android 的“设置 - Google - 广告”或 iOS 的“设置 - 隐私与安全性 - 跟踪”）重置您的广告标识符，或选择退出个性化广告。

（四）信息存储地点与期限

存储地点： 本游戏核心玩法产生的数据（存档、设置等）仅存储于您的设备本地，我们不会将其上传至任何服务器。Google Mobile Ads SDK 收集的数据存储地点详见其自身隐私政策。

存储期限： 本地游戏数据保留至您主动清除应用数据或卸载本游戏时止。Google Mobile Ads SDK 的数据保留期限以其隐私政策为准。

三、我们如何共享、转让、公开披露您的信息

（一）共享

我们不会向任何第三方出售您的个人信息。仅在以下情形下，我们会与第三方共享必要信息：

  • 广告服务商：如第一条第（二）款所述，Google 会直接在其 SDK 内收集上述设备与广告数据。
  • 法律要求：根据法律法规、司法或行政机关的强制性要求，我们可能依法披露相关信息。

（二）转让与公开披露

我们不会将您的个人信息转让给任何公司、组织和个人。除法律强制要求外，我们不会公开披露您的个人信息。

四、未成年人保护

本游戏不面向未满十四周岁的儿童单独提供。 若您是未满十八周岁的未成年人，请在监护人的陪同下阅读本政策，并在取得监护人同意后使用本游戏。如果我们发现在未事先获得可证实的监护人同意的情况下收集了儿童的个人信息，我们将尽快删除相关数据。

如果您是儿童的监护人，请注意：如果您不希望儿童看到个性化广告，请在设备系统设置中关闭广告跟踪功能，或通过 Google 的 Family Link 等服务管理儿童的设备。

五、您的权利

根据《个人信息保护法》及适用的相关法律，您对您的个人信息享有查阅、复制、更正、删除等权利。

由于本游戏为单机游戏，我们不保留您的个人身份信息。针对本地存档，您可直接通过“清除应用数据”或“卸载游戏”进行彻底删除。针对广告信息，您可通过系统设置管理您的广告标识符（如上文所述）。

六、本政策的变更

我们可能适时修订本政策。如修订导致您的权利发生实质性减少，我们将通过游戏内弹窗、公告等显著方式通知您，并重新征得您的同意（如适用）。
